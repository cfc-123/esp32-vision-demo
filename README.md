# ESP32-CAM 视觉识别项目 (esp32-vision-demo)

基于 ESP32-CAM + OpenCV 的嵌入式视觉应用，实现实时人脸检测与色彩识别。
个人项目 · 用于学习与实践「感知 + 控制」闭环开发全流程。

## 📌 项目简介
本项目在 ESP32-CAM（Arduino 框架）端完成图像采集与摄像头参数配置，
通过串口将图像帧发送给上位机（PC），由 Python + OpenCV 完成人脸检测与色彩识别。
最终输出目标在画面中的坐标，可对接机械臂 / 云台做目标追踪。

核心能力标签：嵌入式视觉 · 图像预处理 · 人脸检测 · 色彩识别 · 坐标输出 · 串口通信
